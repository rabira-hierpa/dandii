# Data Model

The complete Prisma schema lives at [`web/prisma/schema.prisma`](https://github.com/rabira-hierpa/dandii/blob/main/web/prisma/schema.prisma). Postgres is the source of truth; this page is the reference for its tables, keys, and constraints.

## Overview

```
                    ┌───────────┐        ┌───────────┐
                    │  Agency   │        │ Operator  │  (ANBESSA|SHEGER|
                    └─────┬─────┘        └─────┬─────┘   MINIBUS|ALLIANCE|LRT)
                          │                    │
                          ▼                    ▼
   ┌──────────────────────────────── Route ──────────────────────────────────┐
   │  id (GTFS route_id) · shortName · longName · type · geojson · length     │
   └───┬───────┬────────┬───────────┬───────────┬───────────┬──────────┬──────┘
       │       │        │           │           │           │          │
       ▼       ▼        ▼           ▼           ▼           ▼          ▼
   Trip →   Fare +   RouteClosure RouteAssign  FareProposal SavedRoute FareChangeLog
StopTime  FareTier   (open/close) (→ Operator) (rider edit)  (user⋈route) (audit)
Frequency

   Users/Sessions/Accounts/Verification ── better-auth tables
   FeedVersion ── one row per generated GTFS export (no relations; monotonic version)
```

## Auth tables (better-auth)

Generated by better-auth's Prisma adapter; do not hand-edit shapes.

| Model | Purpose | Notable fields |
|---|---|---|
| `User` | Account identity | `role` (String; app role), `email` (unique), `banned`, `lastSubmissionsViewedAt` (drives the rider's "unseen decided edits" badge) |
| `Session` | Signed-in session | `token` (unique), `expiresAt`, `userId` |
| `Account` | OAuth link | `providerId`, `accountId`, `userId` |
| `Verification` | Email/OTP flows | `identifier`, `value`, `expiresAt` |

## GTFS core

Straight import of the DT4A feed (see [GTFS Data and Seeding](GTFS-Data-and-Seeding)).

| Model | Key | Notes |
|---|---|---|
| `Agency` | `id` | GTFS agency (single agency in this feed). |
| `Operator` | `code` (unique) | Derived, not in raw GTFS. Enum `OperatorCode`: `ANBESSA`, `SHEGER`, `MINIBUS`, `ALLIANCE`, `LRT`. |
| `Route` | `id` = GTFS `route_id` | `shortName`, `longName`, `type`, `color`, `geojson` + `geojsonSimplified` (Json), `lengthMeters`. Back-relations to proposals, savedBy, fareChangeLog. |
| `Stop` | `id` | Lat/lon, name. |
| `Trip` | `id` | Belongs to a route + calendar. |
| `StopTime` | — | Ordered stops per trip. |
| `Frequency` | — | Headway-based service windows (`startTime`, `endTime`, `headwaySecs`). |
| `Calendar` | `serviceId` | Service days. |

## Fares

| Model | Key | Notes |
|---|---|---|
| `Fare` | `routeId` (unique) | One fare per route. `kind` (`FLAT` \| `TIERED`), `flatAmountEtb` (`Decimal(8,2)`), `currency` (ETB). This is the **live, approved** fare the app reads. |
| `FareTier` | — | Distance bands for `TIERED` fares: `label`, `fromKm`, `toKm?`, `amountEtb`. |

## Management

| Model | Key | Notes |
|---|---|---|
| `RouteClosure` | — | `reason` (enum `ClosureReason`: `PUBLIC_HOLIDAY`, `MAINTENANCE`, `POLITICAL_EVENT`, `OTHER`), `note`, `startsAt`, `endsAt`, `createdById`. A route is "closed" iff an active closure overlaps now (derived, not a flag). |
| `RouteAssignment` | `routeId` (unique) | Maps a route to an `Operator`. `assignedById`, `assignedAt`. |

## Crowdsourced fare registry

The tables that power [Crowdsourced Fares](Crowdsourced-Fares).

### `FareProposal`
A rider-submitted, whole-fare replacement awaiting review.

- `submittedById`, `reviewedById` — **plain Strings, no FK** to `User` (by design): the audit trail survives user deletion or ban, mirroring `RouteClosure.createdById`.
- `status` — enum `ProposalStatus`: `PENDING`, `APPROVED`, `REJECTED`, `SUPERSEDED`.
- `proposedKind` / `proposedFlatEtb` / `proposedTiers` (Json) — the suggested fare.
- `baselineKind` / `baselineFlatEtb` / `baselineTiers` — snapshot of the fare at submission time (nullable; a route may have no fare yet), so the maintainer's diff stays stable.
- `note`, `reviewNote`, `decidedAt`.
- Indexes: `@@index([routeId, status])`, `@@index([submittedById, createdAt])`.
- **Partial unique index** (raw-SQL migration): one `PENDING` proposal per `(routeId, submittedById)`. Prisma can't express partial uniques natively.

### `SavedRoute`
Rider bookmarks. Composite primary key `(userId, routeId)`, plus `createdAt`.

### `FareChangeLog`
Append-only audit trail. Every fare write records before/after images and a `source` (enum `FareChangeSource`: `PROPOSAL_APPROVAL`, `CONSOLE_EDIT`, `RESEED`). `changedById` is a plain String. `RESEED` writes one summary row per seed run. Indexed `@@index([routeId, createdAt])`.

### `FeedVersion`
One row per generated GTFS export.

- `version` (Int, **unique**, monotonic), `label` (`v3`), `filePath`, `sizeBytes`.
- `fareChangeCount`, `generatedById`.
- `validatorStatus` — enum `ValidatorStatus`: `PENDING`, `PASS`, `WARN`, `FAIL` (production generations record `PENDING`; the gate runs in CI).
- `lastChangeLogId` — cursor anchoring the next version's change report (no `createdAt`-window races).

## Constraint cheat-sheet

| Constraint | Where | Why |
|---|---|---|
| `Fare.routeId` unique | `Fare` | One live fare per route. |
| `RouteAssignment.routeId` unique | `RouteAssignment` | One operator per route. |
| `FeedVersion.version` unique | `FeedVersion` | Monotonic export numbering. |
| `SavedRoute` PK `(userId, routeId)` | `SavedRoute` | A route is saved once per user. |
| Partial unique `(routeId, submittedById) WHERE status='PENDING'` | `FareProposal` | One open edit per rider per route. |
| Plain-String `submittedById` / `reviewedById` / `changedById` | proposals, log, closures | Audit survives user deletion. |
